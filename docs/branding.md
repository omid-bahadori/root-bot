# هویت نمایشی و نام‌گذاری

نام نمایشی پیش‌فرض این نسخه `Root Bot` است و از طریق `ROOTBOT_BRAND_NAME` قابل تغییر است:

```bash
export ROOTBOT_BRAND_NAME="نام دلخواه شما"
```

مقادیر زبان و متن‌های پنل/ربات هنگام بارگذاری، نام نمایشی `Root Bot` را با نام انتخاب‌شده جایگزین می‌کنند. شناسه‌های فنی، جدول‌های دیتابیس، مسیرها، متغیرهای محیطی و نام repository نیز با هویت Root Bot هماهنگ شده‌اند؛ این تغییر عمدی و ناسازگار با نام‌گذاری قبلی است.

این تغییر branding، مجوز `AGPL-3.0-or-later` و attribution پروژه‌ی اصلی را حذف نمی‌کند. در انتشار نسخه‌ی مشتق‌شده، notice مجوز و متن متناظر source باید حفظ شود.
